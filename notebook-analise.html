Projeto MENU-LATERAL¶

Feito por João Andre @jandrexm | Última modificação: 05/06/2026



Uma empresa lançou um teste A/B para avaliar a usabilidade do menu lateral de sua plataforma. O teste compara duas configurações:

  1. Acesso direto a uma página específica do site (Nível 0 do menu lateral).
  2. Acesso à mesma página, mas sob uma aba mais geral (Nível 1 do menu lateral).

O objetivo do desafio a seguir foi determinar qual configuração do menu lateral leva a mais acessos e conversões para a página específica da plataforma.

Com a justificativa de que identificar a configuração mais eficaz ajudará a otimizar a navegação do site para aumentar o engajamento dos usuários.

3.2 Teste de normalidade (Shapiro-Wilk)¶

Nesta etapa, verifica-se a distribuição da variável session_duration nos grupos "A" e "B" utilizando o teste de Shapiro-Wilk e análise de histogramas. O objetivo é determinar se a distribuição dos dados segue uma curva normal (Gaussiana), o que orientará a escolha dos testes de hipótese subsequentes.

Obs.: Será utilizado o dataset dados_engajados, corresponde aos dados_tratados sem os zeros.

In [9]:
# i. Segmentação para análise de engajamento (removendo sessões com duração zero)
dados_engajados = dados_tratados[dados_tratados['session_duration'] > 0].copy()

# ii. Histograma de duração de sessão por grupo com teste de normalidade Shapiro-Wilk

fig, axes = plt.subplots(1, 2, figsize=(15, 5), sharey=True)

grupos = sorted(dados_engajados['group'].unique())

posicoes = {'Nível 0': (40, 125), 'Nível 1': (20, 125)}

for i, grupo in enumerate(grupos):
    dados_nivel = dados_engajados[dados_engajados['group'] == grupo]['session_duration']
    
    # Executa o teste de Shapiro-Wilk
    stat, p_valor = shapiro(dados_nivel)
    
    # Histograma
    sns.histplot(data=dados_nivel, ax=axes[i], color='#652643', kde=True, bins=30)
    
    # Preparação do texto
    status = "Parece normal" if p_valor > 0.05 else "Não é normal"
    texto_resultado = f"Shapiro-Wilk:\nEstatística W: {stat:.2f}\np-valor: {p_valor:.2e}\n\nConclusão:\n{status}"

    # Posicionamento dinâmico
    x_pos, y_pos = posicoes[grupo]
    axes[i].text(x_pos, y_pos, texto_resultado, fontsize=9, bbox=dict(facecolor='white', alpha=0.9, edgecolor='gray', boxstyle='round,pad=0.5'))
    axes[i].set_title(f'{grupo}', fontsize=10)
    axes[i].set_xlabel('Duração da sessão (s)')
    axes[i].set_ylabel('Frequência' if i == 0 else '')
    axes[i].grid(axis='y', linestyle='--', alpha=0.5)  

plt.suptitle('Histogramas de duração de sessão por grupo (engajamentos)', fontsize=14, y=1.05)

plt.savefig(os.path.join(DIRETORIO_PLOTS, 'histograma_normalidade.png'), dpi=300, bbox_inches='tight')
plt.show()

A análise dos histogramas (acima) e os resultados do teste de Shapiro-Wilk confirmam a ausência de normalidade em ambos os grupos (p-valor < 0.05). Além disso, a visualização evidencia uma distribuição assimétrica, em que a maior parte dos usuários apresenta engajamentos curtos, enquanto uma cauda longa representa usuários de alta permanência.

Dado o não cumprimento da premissa de normalidade, testes paramétricos, como o Teste-T, tornam-se tecnicamente inadequados. Portanto, o Teste U de Mann-Whitney será adotado para a análise de significância estatística.

3.3 Teste U de Mann-Whitney¶

Este é um método não-paramétrico robusto que compara as distribuições e as medianas de duas amostras independentes. Sua principal vantagem nesse contexto é a resistência a outliers (valores extremos), garantindo que sessões longas não distorçam a avaliação geral entre os cenários/grupos.

In [56]:
# i. Isolando as amostras dos dois grupos na base de engajados
grupo_nivel_0 = dados_engajados[dados_engajados['group'] == 'Nível 0']['session_duration']
grupo_nivel_1 = dados_engajados[dados_engajados['group'] == 'Nível 1']['session_duration']

# ii. Executando o Teste de Mann-Whitney U (Bicaudal)
stat, p_valor = mannwhitneyu(grupo_nivel_0, grupo_nivel_1, alternative='two-sided')

# iii. Exibição dos resultados
print("Teste de Mann-Whitney U --------------------")
print(f"Estatística U: {stat:.2f}")
print(f"p-valor:       {p_valor:.2e}")
print("-" * 44)

# iv. Interpretação automática dos resultados
nivel_significancia = 0.05

if p_valor < nivel_significancia:
    print("***Rejeitamos a hipótese nula (H0)***\n(HÁ uma diferença estatisticamente significativa entre os grupos).\n")
else:
    print("***Não rejeitamos a hipótese nula (H0)***\n(NÃO há uma diferença estatisticamente significativa entre os grupos).\n")
print("-" * 44)

# iv. Resumo de medianas de session_duration por grupo
print("\nResumo de engajamento por grupo:")
print(f"Mediana Nível 0: {grupo_nivel_0.median():.2f} segundos")
print(f"Mediana Nível 1: {grupo_nivel_1.median():.2f} segundos\n")

# v. Resumo de médias de session_duration por grupo
print(f"Média* Nível 0: {grupo_nivel_0.mean():.2f} segundos")
print(f"Média* Nível 1: {grupo_nivel_1.mean():.2f} segundos")
print("* Média é sensível a outliers, por isso a mediana é mais confiável para esta análise.")
print("-" * 44)
